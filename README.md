# Стартапы: анализ рынка

Из первого списка остались три проекта. По каждому проведён анализ рынка (сентябрь 2026).

| Проект | Есть ли хорошее решение на рынке | Главный конкурент | Размер рынка | Вердикт |
|---|---|---|---|---|
| [Татарский язык](market/tatar.md): самоучитель с грамматикой, приложение, традиции | **Нет.** Duolingo татарского не поддерживает, приложения — словари и карточки | «Ана теле» (бесплатный, устаревший) | маленький: около 1,45 млн татар не владеют языком + школьники | ✅ ниша свободна, но денег мало; модель подписка + гранты + школы |
| [AI-аудиогид](market/audioguide.md) для любого места и маршрута | **Да, занято.** Audiala и десятки клонов | Google Maps + Gemini в мире, Яндекс Карты (бесплатные AI-маршруты) в РФ | $1,75–2,9 млрд в мире, маленькие чеки | ⚠️ только ниша: русскоязычные туристы за рубежом |
| [Аналог Snowball Income](market/snowball.md) с AI-стратегом | **Частично.** Snowball, Intelinvest; AI-ассистенты у брокеров | Snowball (AI с 09.2026), «Второе мнение» Сбера | 42,5 млн клиентов Мосбиржи, из них около 3 млн активных | ✅ как «планировщик пассивного дохода», а не клон трекера |

> Цифры собраны из поисковой выдачи: сторы, сайт Мосбиржи и часть СМИ напрямую не открывались. Пункты с пометкой **[не проверено]** в файлах нужно перепроверить руками.
